Interactive Power BI sales dashboard analyzing sales, profit, quantity, and category trends.

# Sales Dashboard Analysis

## About the project
This is my first Power BI dashboard project. I used a sales dataset from Kaggle, cleaned and modified the data in Excel, then created a dashboard in Power BI to explore sales performance.

## What I did
- Removed duplicate records and prepared the dataset in Excel
- Created KPI cards for sales, profit, and quantity
- Built charts to explore sales over time and by category
- Practiced presenting data in an interactive dashboard

## Tools
- Microsoft Excel
- Power BI
- Kaggle dataset

## Dataset
The dataset was downloaded from Kaggle.  


## Learning and next steps
I’m continuing to improve this project by refining the dashboard layout, adding useful filters, and learning more about data analysis and Power BI.
